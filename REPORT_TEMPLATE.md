# Project Report: Predicting Term Deposit Subscription

## Problem

This project studies whether a client subscribed to a term deposit during a Portuguese bank's historical phone campaign. The goal is to demonstrate a custom binary classifier and a careful evaluation workflow. A prediction is a historical-pattern estimate, not a causal claim about the effect of contacting a client.

## Dataset

The project uses the full Bank Marketing dataset from the UCI Machine Learning Repository: 45,211 records, 16 input variables, and the binary target `y`. The modeling notebook downloads the official archive and reads `bank-full.csv` from the nested ZIP file at runtime. The source is attributed to S. Moro, P. Rita, and P. Cortez, UCI DOI `10.24432/C5K306`, CC BY 4.0.

The model uses 11 pre-contact inputs: age, job, marital status, education, default status, balance, housing loan, personal loan, contact method, day, and month. It drops `duration` because it is measured after a call, and drops `campaign`, `pdays`, `previous`, and `poutcome` to avoid relying on final campaign-history information.

## Preprocessing and model

The split is stratified into 70% training, 15% validation, and 15% test rows, with seed 42. Numeric values are median-imputed and standardized using training rows only. Categorical values are one-hot encoded using categories learned from training rows only; unseen categories receive a separate indicator.

The classifier is logistic regression implemented from scratch with NumPy. Full-batch gradient descent minimizes binary cross-entropy with L2 regularization. The regularization strength is selected on validation average precision. A probability threshold is chosen on validation F1, then held-out test metrics are calculated once.

## Interpretation, challenges, and limits

The target is imbalanced, so accuracy can hide poor identification of subscribers. Interpret precision and recall together, and explain the chosen operating threshold. Compare training and validation loss and ROC AUC when discussing overfitting or underfitting. A small gap on this random split does not establish generalization to a future campaign.

Potential sources of error include historical changes in campaign practice, incomplete pre-contact information, category shifts, and the difference between observed subscriptions and the causal effect of a phone call. Before real use, test on a later campaign period, check calibration and group-level error rates, and review consent and campaign policies.
