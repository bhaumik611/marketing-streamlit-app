# Bank Marketing Classification: Colab Project Package

This package addresses the course brief with a real-world binary classification problem: estimate whether a client subscribed to a term deposit in a historical Portuguese bank phone campaign. The model is handwritten logistic regression trained with NumPy gradient descent. Pandas is used for tabular data handling and Matplotlib for visualizations; no machine-learning library is used for the model, data split, encoding, optimizer, or metrics.

The package is organized around the requirements in the supplied course brief: a realistic dataset, a custom model, preprocessing, visual exploration, evaluation, fit analysis, a report, presentation material, code, and a demonstration path.

## Files

- `notebooks/01_Explore_UCI_Bank_Marketing.ipynb` downloads the dataset in Colab, profiles it, and saves exploratory charts.
- `notebooks/02_Scratch_Logistic_Regression_and_Demo.ipynb` is the complete standalone modeling notebook. It independently downloads the data, preprocesses it, trains and tunes the scratch model, evaluates it, analyzes fit, makes one illustrative prediction, and saves outputs.
- `src/bank_marketing_core.py` contains readable reusable source for the custom pipeline.
- `src/streamlit_app.py` is an interactive web demonstration. It downloads and trains automatically on first load; no dataset or model upload is needed.
- `REPORT_TEMPLATE.md` is the report source. The modeling notebook also writes a filled `project_report.md` using the metrics actually measured when it runs.
- `PRESENTATION_SOURCE.md` is a slide-by-slide presentation source. The modeling notebook writes a `presentation_results.md` page with real values after execution.
- `requirements.txt` lists the dependencies for the Streamlit web demonstration. Google Colab already supplies the notebook's NumPy, pandas, and Matplotlib dependencies.

## Run in Google Colab

1. Open `01_Explore_UCI_Bank_Marketing.ipynb` in Google Colab and choose **Runtime → Run all**. The notebook fetches the public UCI ZIP archive and reads `bank-full.csv` from its nested ZIP. No dataset upload is required.
2. Open `02_Scratch_Logistic_Regression_and_Demo.ipynb` in Colab and choose **Runtime → Run all**. It is standalone, so you can also run it directly without running notebook 01 first.
3. At the end of notebook 02, use its optional download cell to download `bank_marketing_project_outputs.zip` to your computer. Colab's `/content` storage is temporary, so download the ZIP before ending the session.

The notebooks contain no saved/fabricated metric outputs. All reported scores and plots are generated by executing the cells against the downloaded dataset. The project output folder includes a metrics JSON/CSV, test predictions, validation tables, coefficients, preprocessing metadata, saved model weights, and chart images.

## Dataset and prediction scope

UCI reports 45,211 records and 16 input variables for the full Bank Marketing dataset. This project uses 11 variables available before the current phone call: age, job, marital status, education, default status, account balance, housing loan, personal loan, contact method, day, and month.

The target is `y` (`yes` or `no`). `duration` is excluded because call duration is known only after the call. `campaign`, `pdays`, `previous`, and `poutcome` are also excluded because their final campaign-history values may include information from later contacts. This makes the task closer to pre-contact prioritization, but the remaining historical data still does not prove future performance.

The source archive is fetched from the [UCI Bank Marketing dataset](https://archive.ics.uci.edu/dataset/222/bank%2Bmarketing). UCI identifies the dataset authors as S. Moro, P. Rita, and P. Cortez, DOI `10.24432/C5K306`, and the license as CC BY 4.0. The notebook reports the attribution in saved outputs.

## Method and evaluation

- Split: reproducible stratified 70% train, 15% validation, 15% test; seed 42.
- Preprocessing: training-only median imputation and standardization for numeric fields; training-only category vocabulary and one-hot encoding for categorical fields; unseen categories get an explicit indicator.
- Model: binary logistic regression coded from scratch, optimized with full-batch gradient descent and L2 regularization.
- Selection: choose L2 strength by validation average precision; select the classification threshold by validation F1. The test split is evaluated once after selection.
- Metrics: accuracy, precision, recall, specificity, F1, ROC AUC, and average precision. ROC and precision-recall curves are also saved.
- Fit analysis: compare training and validation loss and ROC AUC, and report a simple overfit/underfit diagnostic. The diagnostic is a prompt for interpretation, not proof.

Because the positive class is less common, accuracy alone is not an adequate summary. Discuss precision and recall together with ROC AUC and average precision, and explain the validation-selected threshold.

## Web demonstration & Streamlit Deployment

### 1. Run Locally
From the package root directory:

```bash
# Install dependencies
pip install -r requirements.txt

# Launch the Streamlit application
streamlit run app.py
# (or: streamlit run src/streamlit_app.py)
```

The app loads the pre-trained weights (`scratch_logistic_model.npz`), the preprocessor configuration, and the local `bank-full.csv` dataset in milliseconds without retraining or external downloads.

### 2. Deploy to Streamlit Community Cloud (Free Hosting)

1. **Push to GitHub**:
   - Initialize a git repository if not already done:
     ```bash
     git init
     git add .
     git commit -m "Deploy Bank Marketing Streamlit App"
     ```
   - Create a GitHub repository and push your code:
     ```bash
     git remote add origin https://github.com/<your-username>/<your-repo-name>.git
     git branch -M main
     git push -u origin main
     ```

2. **Deploy on Streamlit Cloud**:
   - Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
   - Click **"New app"**.
   - Select your repository and branch (`main`).
   - Set **Main file path** to `app.py` (or `src/streamlit_app.py`).
   - Click **"Deploy"**.
   - Streamlit Cloud will automatically detect `requirements.txt`, install dependencies, load the trained model (`scratch_logistic_model.npz`), and launch the live web app with a shareable URL.

## Limits and responsible use

This is a course demonstration using historical data. A random split does not measure performance on a later campaign, and no customer should be contacted solely because of a model score. Before any operational use, evaluate on a later time period, check calibration and group-level error rates, review consent and campaign rules, and obtain domain approval.
